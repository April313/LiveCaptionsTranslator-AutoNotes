# 源码补丁说明

这里是相对上游 [SakiRinn/LiveCaptions-Translator](https://github.com/SakiRinn/LiveCaptions-Translator)
的改动文件。把它覆盖到上游源码树上，就能重新编译出本包里的程序。

## 改动清单

| 文件 | 作用 |
|---|---|
| `src/utils/AutoNotesService.cs` | 核心：收集字幕 → 调 Ollama 生成 Markdown → 调 DeepSeek-R1 整合去重 |

| `src/windows/MainWindow.xaml` | 侧边栏加入 Auto Notes 入口 |
| `src/App.xaml.cs` | 页面注册 |
| `src/Translator.cs` | 字幕同步循环里把完成的字幕喂给笔记服务 |
| `src/utils/TextUtil.cs` | 文本清洗（去重复、去空白、剔除思考标签） |

## 重新编译

```powershell
# 先准备上游源码
git clone https://github.com/SakiRinn/LiveCaptions-Translator.git C:\src\LiveCaptions-Translator

# 覆盖补丁并编译（自动找 .NET SDK，必要时用户级安装）
powershell -ExecutionPolicy Bypass -File .\编译安装补丁.ps1 -SourceDir C:\src\LiveCaptions-Translator -SkipInstall
```

产物：

- `publish\LiveCaptionsTranslator.exe` —— 单文件自包含
- `publish-fdd\` —— 框架依赖版（对应包里的 `fdd\`）

编译完成后，把这两个产物按本包结构替换即可：

```text
publish\LiveCaptionsTranslator.exe   ->  LiveCaptionsTranslator-AutoNotes.exe
publish-fdd\*                        ->  fdd\
```

## 整合逻辑的安全边界

`AutoNotesService.ConsolidateNotesAsync` 的顺序是刻意设计的：

1. 读全部 `note-*.md` + 已有 `consolidated.md`
2. 调 `deepseek-r1:7b` 折叠合并（超长按 12000 字分块多轮）
3. 写 `consolidated.md.tmp`，确认非空
4. 原子替换 `consolidated.md`
5. **第 4 步成功后**才删除已整合的 `note-*.md`

任何一步失败或用户取消，分段笔记都保留。删除范围严格限定在文件名匹配 `note-*.md` 的文件。
