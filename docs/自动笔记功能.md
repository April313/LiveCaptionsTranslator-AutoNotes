# 自动笔记功能说明

给 [LiveCaptions-Translator](https://github.com/SakiRinn/LiveCaptions-Translator) 加的一个模块：把实时字幕自动整理成简体中文 Markdown 笔记，全部走本机 Ollama，字幕不出本机。

## 它做了什么

- 主窗口左侧新增 **Auto Notes** 页
- 自动收集**已完成翻译**的字幕（没翻译完的不收，避免半截句子）
- 每累计 N 条字幕，调用本机 Ollama 生成一份笔记，含：
  - 摘要
  - 关键要点
  - 待办事项
  - 重要术语
  - 原始英文字幕 + 对应中文翻译
- 支持「立即生成」当前摘要，不必等攒够 N 条
- 支持「立即整合并清理」：把已有分段笔记合并去重成一份
- 可多选指定要整合的笔记；不选则处理全部
- 笔记目录可配置；默认只访问 `http://localhost:11434`，不依赖任何外部翻译 API

## 界面里的设置项

| 设置 | 说明 | 建议值 |
|---|---|---|
| 自动生成笔记 | 总开关 | 开启 |
| 每多少条字幕生成一次 | 攒够多少条触发一次 | 20 ~ 30（模型慢就调大） |
| Ollama 模型 | 用来写笔记的模型 | `qwen2.5:7b` |
| Ollama 地址 | 本地服务地址 | `http://localhost:11434` |
| 笔记保存目录 | 相对路径按程序目录解析 | `notes` 或绝对路径 |
| 生成后自动整合并清理分段笔记 | 见 `笔记整合与去重.md` | 开启 |
| 整合模型 | 用来合并去重的模型 | `deepseek-r1:7b` |
| 整合结果文件名 | 唯一保留的汇总文件 | `consolidated.md` |

模型越大越准、越慢；7B 在 8GB 显存的笔记本上大约 5~15 秒出一次笔记。显存吃紧可以把批量调到 30~50，或把笔记模型换成 `qwen2.5:3b`。

## 完全离线怎么验

首次安装、下载模型、下载 Windows 实时字幕的英语语音包都需要联网。这些做完之后：

1. 确认 `ollama list` 里能看到 `qwen2.5:7b`（整合还需要 `deepseek-r1:7b`）。
2. 确认实时字幕的英语语言包已下载。
3. 断网。
4. 启动 Ollama 和本程序。
5. 播放英文视频，等 `notes\` 下出现 Markdown 文件。

只要 Ollama 地址保持在 `localhost`，程序不会把字幕内容发到外部服务。

src/App.xaml.cs                        页面注册
src/Translator.cs                      字幕流水线接入笔记服务
