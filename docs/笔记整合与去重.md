# DeepSeek-R1:7B 笔记整合与去重

## 安装模型

在 Windows PowerShell 执行：

```powershell
ollama pull deepseek-r1:7b
```

确认模型存在：

```powershell
ollama list
```

## 工作方式

当一批字幕生成 `note-*.md` 后，如果开启“生成后自动整合并清理分段笔记”，程序会：

1. 读取当前目录中的所有 `note-*.md`。
2. 读取已有的 `consolidated.md`（如果存在）。
3. 调用本地 Ollama 的 `deepseek-r1:7b`。
4. 写入临时文件并确认非空。
5. 原子替换 `consolidated.md`。
6. 只有第 5 步成功后，才删除已经整合的 `note-*.md`。

如果 Ollama 调用失败、返回空内容或程序被取消，原始分段笔记会保留，不会删除。

## 推荐设置

```text
自动生成笔记：开启
笔记整合与去重：开启
摘要模型：qwen2.5:7b
整合模型：deepseek-r1:7b
Ollama 地址：http://localhost:11434
整合结果：consolidated.md
```

## 输出

最终目录只保留一个持续更新的文件：

```text
consolidated.md
```

它包含：

- 摘要
- 关键知识点
- 会议结论
- 待办事项
- 未解决问题
- 重要术语

程序会删除的文件仅限名称匹配 `note-*.md` 的分段笔记，不会删除其他 Markdown 文件。
